旅遊網站產生器

填一份 Excel，產生一個可離線使用的行程網站。檔案只在你的瀏覽器裡處理，不會上傳到任何伺服器。

1準備資料

首爾行程已經填在模板裡當範例，可以照著改，也可以整批刪掉重填。

下載 Excel 模板
想在線上編輯（手機也能改） 1. 把上面的檔案上傳到 Google 雲端硬碟
2. 雙擊開啟 → 這時它還是 Excel 檔
3. 檔案 → 另存為 Google 試算表　←　這步不能跳過
4. 會產生「新的一份」，網址跟原本不同，之後都用新的
5. 新檔案按「共用」→ 知道連結的任何人 → 檢視者
判斷方式：檔名旁邊還有綠色 XLSX 標籤就是還沒轉檔， Sheets API 讀不了 Office 格式的檔案。

2讀取資料

線上改完按「讀取」就好，不用下載。怎麼申請 API 金鑰？

申請 Google API 金鑰（一次就好） 1. 開 Google Cloud Console → 建立專案，名稱隨意
2. 左側「API 和服務」→ 已啟用的 API 和服務 → 啟用 API 和服務 → 搜尋 Google Sheets API → 啟用
3. 左側「憑證」→ 建立憑證 → API 金鑰 → 複製那串 AIza...
4. 點該金鑰 → 編輯 → API 限制 → 限制金鑰 → 只勾 Google Sheets API → 儲存
第 4 步是重點：限制之後這把金鑰只能讀試算表，不能做別的事。

3雲端同步

已經填好共用的設定，不用動。所有旅程共用同一個 Firebase 專案，靠「行程代號」分開資料。
這趟不想用雲端同步的話，把內容清空即可（改成單機模式，資料只存在瀏覽器）。

4自動部署（可留空）

填好之後就能一鍵推上 GitHub，GitHub Pages 會自動發佈。留空的話改用下載 zip 手動上傳。 怎麼申請權杖？

申請 GitHub 細粒度權杖 1. 開 github.com/settings/personal-access-tokens/new
2. Token name 隨便填，Expiration 選一個期限
3. Repository access → Only select repositories → 挑你放網站的那個 repo
4. Permissions → Repository permissions → Contents 改成 Read and write
5. 產生後複製那串 github_pat_...，離開頁面就看不到了
只勾這個 repo 跟 Contents 權限，就算外流別人也只能改這個行程網站。
