## 二、設計 token

全部定義在 `:root`，元件裡不寫死 hex（唯一例外是 `.wx-grid div + div` 的 `rgba(0,0,0,.06)` 分隔線）。

### 語意色

| token | 值（maple 主題） | 用在哪 |
|---|---|---|
| `--c-bg` | `#FAF8F5` | 頁面底色 |
| `--c-surface` | `#FFFFFF` | 卡片底色 |
| `--c-text` | `#3B3733` | 正文 |
| `--c-text-dim` | `#6B635B` | 次要文字（在五個主題的底色上最低 5.1:1，**不要調淡**） |
| `--c-line` | `#E7E1D8` | 分隔線與結構線：路線的灰段、進度條軌道、卡片狀態的左邊框、各種 `border-top／bottom`（20 處） |
| `--c-border` | `#8A8278` | **只給控制項的邊框**：輸入框、chip、分頁膠囊、`.btn-plain`、檔案選擇、`.secret-ask`、`#edit-bar a`（11 處）。WCAG 1.4.11 要介面元件的邊界 ≥ 3:1，這個值對淺色底最差 3.27、深色底最差 3.17，所以深色模式不用另外覆寫 |
| `--c-accent` | `#F5D2C8` | 淡色底：選取中的分頁、標籤、`.time`、「現在」卡片的底 |
| `--c-accent-soft` | `#FCF0EC` | 更淡的底：說明框、天氣格、預報卡 |
| `--c-on-accent` | `#A33A2A` | 疊在 `--c-accent` 上的字；也是小標題、連結文字的顏色 |
| `--c-accent-strong` | `= --c-on-accent` | 線、圓點、進度條（沒有文字疊上去的地方） |
| `--c-pop` | `#1F7A73` | 主題色的互補色，`.btn-theme` 用 |
| `--c-warn` / `--c-warn-text` / `--c-warn-soft` | `#E0A458` / `#9A6210` / `#FDF4E7` | 提醒框左邊線 / 提醒文字 / 提醒底色 |
| `--c-danger` / `--c-ok` | `#C9302C` / `#2A7F52` | 刪除、額度用完 / 同步正常 |
| `--c-naver` `--c-booking` `--c-map` | `#027A38` `#A33A2A` `#1A73E8` | 外部服務按鈕（固定，不隨主題） |
| `--c-on-solid` | `#FFFFFF` | 深色實心按鈕上的字 |

三者的關係要一起算：`--c-accent` 是底色、`--c-on-accent` 是疊在上面的字（≥ 4.5:1），
`--c-accent-strong` 是同一色的深版，給 4px 的線這種白底上看不見淡色的地方。

上面是淺色的值。深色模式在 CSS 最後一塊 `@media (prefers-color-scheme: dark)` 整組覆寫，
明暗角色對調（`--c-accent` 變成深底、`--c-on-accent` 變成淺字），細節見第七節。

## 三、版面與斷點

| 寬度 | 版面 |
|---|---|
| < 600px | 單欄，`--w-app` 480px，`main` 左右各 16px 內距 |
| ≥ 600px | 單欄加寬到 600px，內距移到 `body` |
| ≥ 1024px | 兩欄 grid `300px / 1fr`，上限 960px。左欄＝標題＋天氣＋直向分頁（sticky），右欄＝行程。根字級固定 17px，卡片內距加大到 24px |
| ≥ 1280px | 有嵌入金鑰時三欄 `300 / 720 / 360+`，上限 1500px，地圖 sticky 滿版高 |
| ≥ 1440px | 沒有地圖時兩欄上限 1100px（`.app.map-on` 兩個 class 的優先序較高，所以有地圖時仍是 1500px 三欄） |

`map-on`（網站有金鑰＋電腦寬度）與 `has-map`（這一頁有地圖）**刻意分開**：
否則切到沒有地圖的分頁時版面會從 1560px 縮回 1020px 重新置中，左欄橫向跳將近 200px。

安全區：`body` 補 `env(safe-area-inset-top/bottom)`，`.nav-bar` 的 `top` 與 `.sync`、`.toast`
的 `bottom` 也各自算進去。`html` 的 `scroll-padding-top:80px` 讓取得焦點的元素不被 sticky 分頁列蓋住。

## 七、無障礙現況

### 已經做到的

- 觸控目標一律 ≥ 44×44px。外觀小的元素用「padding 撐大 ＋ 等量負 margin 抵掉」保持版面不變：電話、照片出處、頁尾連結、`.secret-lock`；`.shop-x` 的 28px 圓圈用 `::after` 撐熱區（測試特別排除它本體）。
- 焦點外框 2px＋2px offset，六類互動元素共用一條規則。
- 不用 emoji 當圖示（只有使用者自己寫的網站標題例外，測試排除 `#app-title`）；圖示都是 `aria-hidden` 的 SVG，旁邊一定有文字。
- 圖示按語意上色，但顏色不是唯一線索（旁邊都有文字）。
- 輸入框都有看得見的 `<label>`（`.f-lbl` 直接包住輸入框，或 `for` 指到 id）；地圖的勾選框用 `aria-labelledby` 指到旁邊的地點按鈕。提示文字只當範例。
- 輸入框 16px 字、44px 高（小於 16px iPhone 會放大畫面）；數字欄用 `inputmode="numeric"`。
- `prefers-reduced-motion` 時裝飾圖層與偽元素動畫都關掉（`*` 不會套到 `::before`／`::after`，所以另外寫）。
- 自己設了 `display` 的元素額外補 `選擇器[hidden]{display:none}`（`.now-line`、`#edit-bar`）。
- 圖片有替代文字（介紹照片用景點名稱、購物縮圖用品名）。
- `viewport` 沒有禁止縮放。

### `tests/offline_test.py` 第 12 段在守的（改壞會直接失敗）

375px 下逐一打開 11 個分頁（並展開所有 `<details>`、按開密語框）量：
文字對比 ≥ 4.5:1（大字 3:1）、觸控目標 ≥ 44×44px、目標間距 ≥ 8px、圖片有 alt、
標題層級不跳級、介面沒有 emoji、輸入框有看得見的標籤、取得焦點的密語框沒被分頁列蓋住、
375px 不會橫向捲動。另外兩個情境：`reduced-motion` 下沒有動畫在跑、1400px 下輸入框也都有標籤。

### 2026-10-25 補上的

| 項目 | 怎麼做的 |
|---|---|
| 分頁的 tab 語意與鍵盤操作 | 每顆分頁有 `id="tab-<dayid>"` 與 `aria-controls="main"`；`<main>` 是 `role="tabpanel"` ＋ `aria-labelledby` 指回選取中的分頁。roving tabindex：只有選取中的那顆是 Tab 鍵的停留點，其餘用 ←→↑↓ 走（手機橫向、電腦直向，所以四個方向都收），Home／End 跳頭尾。**代價：`<main>` 的 role 被 `tabpanel` 蓋掉，失去 main 地標**——改用下面的「跳到主內容」補回同樣的用途 |
| 標題層級 | 卡片標題 `.subject` 從 `div` 改成 `h2`，清單群組從 `h2` 降成 `h3`。現在是 h1（網站標題）→ h2（卡片）→ h3（清單群組），讀螢幕可以跳著讀。CSS 補 `margin:0 0 var(--sp-1)` 歸零瀏覽器預設，外觀完全沒變（實測仍是 18.4px／700／`margin:0 0 4px`） |
| 放大檢視 | 開啟時把縮圖的 `alt` 複製到放大的那張圖，對話框也設 `aria-label`（「<品名>（放大）」） |
| 跳到主內容 | `<a class="skip" href="#main">` 放在 body 最前面，鍵盤第一個 Tab 就是它，按下去焦點落在 `#main`（所以它要 `tabindex="-1"`）。平常用 `left:-9999px` 移出畫面——`display:none` 與 `visibility:hidden` 會讓它根本不能被聚焦 |
| 記帳的群組標籤 | 「我是誰」「誰付錢」「分攤對象」改成 `role="group"` ＋ `aria-labelledby` 指到旁邊的標題（`.f-grp`，樣式與 `.field > label` 共用）。原本是沒有 `for` 的 `<label>`，等於一段純文字 |
| 深色模式 | 檔案最後一段自成一塊，由 `<html data-scheme>` 決定（**不是** `@media`，因為可以手動切，見下一段）。五個主題各一套底色／`--c-surface`／`--c-accent`／`--c-accent-soft`／`--c-on-accent`，其餘語意色（文字、線、提醒、刪除、同步、六個圖示色、兩階陰影）不分主題。`--c-pop` **刻意不覆寫**——原本的深飽和色配白字仍有 4.6–5.4:1，改淺反而會讓 `.btn-theme` 的白字糊掉 |

#### 配色可以手動切（2026-10-26）

頁首右上角一顆 44×44 的圖示鍵，點一下換下一個：**跟隨系統**（`circle-half`）→
**淺色**（`sun`）→ **深色**（`moon`）。只有圖示，名稱靠 `aria-label`（「配色：淺色（點一下換下一個）」）。

| 怎麼做的 | |
|---|---|
| 狀態放哪 | `<html data-scheme="light\|dark">`。CSS 用 `:root[data-scheme="dark"]`，不是 `@media`——媒體查詢沒辦法被使用者的選擇蓋過 |
| 偏好存哪 | `localStorage` 的 `travel:scheme`（`auto`／`light`／`dark`）。**刻意不帶 tripId**，同網域下所有行程共用一個偏好 |
| 不要閃白底 | `<head>` 裡一小段同步腳本在繪製前就把 `data-scheme` 設好。放在模組裡不行——模組跑到的時候畫面已經畫完了 |
| 跟隨系統時 | JS 監聽 `prefers-color-scheme` 的變化，系統換了跟著換 |
| 原生控制項 | `:root[data-scheme]` 同時設 `color-scheme`，下拉選單與捲軸才會跟著深色 |
| 標題要讓開 | `header h1` 左右各讓 `calc(44px + var(--sp-2))`。兩側都讓是為了維持置中；電腦版標題靠左，只讓右邊。實測 375px 仍是兩行 |

#### 深色模式裡「光換 token 不夠」的幾個地方

這幾條是實際量出來才發現的，不是推出來的：

| 地方 | 為什麼 |
|---|---|
| `.btn`、`.skip` | 底色是 `--c-text`。深色模式下 `--c-text` 變成淺的，白字就看不見了，所以字改用 `--c-bg` |
| `.btn-plain`／`.btn-route`／`.btn-theme` | 上面那條 `.btn{ color }` 寫在它們後面，同樣是一個 class 的優先序，會把它們的 `color` 一起蓋掉。**四個變體都要在深色區塊裡重新宣告一次**——不補的話外框按鈕會變成深字配深底，實測 1.10:1 |
| `.chk input`／`.vault-remember input` 的 `accent-color` | 原本吃 `--c-accent`，那在深色模式是「底色」用的深色，拿來當勾勾看不見，改用 `--c-on-accent` |
| `.wx-grid` 的分隔線 | 寫死 `rgba(0,0,0,.06)`，在深底上等於沒有，改成 `rgba(255,255,255,.1)` |
| 「看介紹」鋪的照片 | 深色模式的字是淺的，照片要從 `.25` 壓到 `.15` 才不會吃掉對比 |
| `--c-accent-soft` 要**比 `--c-surface` 亮** | 第一版照淺色的直覺做成「比卡片再暗一點」，結果區別度只有 1.02–1.05（1.00 ＝ 完全同色），說明框、`.time`、天氣格整個消失。深色模式的層次是靠「亮」表達的，現在五個主題都比卡片亮一階（1.27–1.36）。**對比探針只量文字，量不到這種「面跟面分不開」**——是使用者看畫面發現的，現在有測試在守 |

嵌入的 Google 地圖永遠是淺色的，控制不了（只有電腦版會出現）。

### 還沒做

第七節原本列的六條都補上了。深色模式有測試在守（第 12 段多一個 `color_scheme="dark"`
的情境，逐一打開 11 個分頁量對比），所以之後改淺色忘了改深色會直接失敗。

## 八、動態效果

| 還在跑的 | 哪裡 |
|---|---|
| 背景裝飾飄落／上升 | `body::before` 跑 `--anim-a` 24s、`body::after` 跑 `--anim-b` 17s，兩層速度與路徑都不同，避免整片同步平移。maple／snow／sakura 是 `driftA`／`driftB`（由上往下），ocean 是 `riseA`／`riseB`（由下往上），city 與 none 是 `none`。**這是 motion-meaning 的例外，使用者指定要留** |

| 捲動 | 切分頁回頂端、第一次捲到目前項目（`behavior:"smooth"`，reduced-motion 時改 `auto`） |
